# 海克斯先知

一个面向英雄联盟海克斯大乱斗 26.12 版本的静态攻略网页原型。

## 运行

直接打开 `index.html`，或在本目录启动任意静态文件服务器。

页面会从 Riot Data Dragon 16.12.1 加载全英雄、皮肤原画和装备资料，因此首次打开需要联网。

## 当前推荐逻辑

- 每个英雄至少提供两套可切换的海克斯与装备构筑，侧重点互不相同。
- 亚索、金克丝、盖伦、拉克丝、薇恩有两套专属策略覆盖。
- 其他英雄根据 Riot 的首要职业标签映射到两套射手、法师、刺客、战士、坦克或辅助模板。
- 推荐结果属于机制驱动的策略评级，不代表实时胜率。
- 数据模型已按英雄覆写与职业模板分层，后续可直接增加英雄专属配置或替换成统计 API。
